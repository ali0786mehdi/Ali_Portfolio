The mental model

RAG is search plus generation.

A language model knows patterns, but it may not know your private or current information. RAG first retrieves relevant source text, then gives that text to a model as evidence before it writes an answer.

01 / INGEST

Collect knowledge

Documents can come from PDFs, websites, databases, or notes. Production systems also preserve source, permissions, and version metadata.

02 / INDEX

Make it searchable

Long documents are split into chunks. Each chunk is embedded and stored in a vector database alongside its original text.

03 / RETRIEVE

Find evidence

The question searches the index. Hybrid search, filters, and reranking help select the best evidence instead of sending everything to the model.

04 / GENERATE

Answer with proof

The model receives the question and selected chunks. A strict prompt asks it to stay within the evidence and cite its sources.
