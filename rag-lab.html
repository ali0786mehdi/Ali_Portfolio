System design

From raw data to reliable response.

01

Data ingestion

Normalize PDFs, Markdown, web pages, and database rows. Keep source URL, title, access rules, and version metadata attached to every document.

load → clean → dedupe → version
02

Chunking & embeddings

Split by semantic boundaries with overlap. Store embeddings alongside the original text and metadata in a vector database.

chunk_size · overlap · model
03

Hybrid retrieval

Combine dense vector search with keyword search, metadata filters, and a reranker to improve recall without flooding the context window.

vector + BM25 → rerank → top-k
04

Grounded generation

Use a strict prompt, context budget, conversation memory, and structured citations. Abstain when the evidence is insufficient.

context → LLM → citations
